
# Ivy Crew - Premium Apparel E-Commerce

  A modern, responsive e-commerce website for Ivy Crew's premium men's and women's apparel.

  ## Features

  - 🛍️ Full e-commerce functionality with cart and checkout
  - 💬 AI-powered chat widget for customer support
  - 🎁 Rewards program integration
  - 📱 Fully responsive design (mobile, tablet, desktop)
  - ⚡ Built with React, TypeScript, Vite, and Tailwind CSS

  ## Running the code

  Run `pnpm i` to install the dependencies.

  Run `pnpm run dev` to start the development server.
